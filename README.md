# World Happiness Analytics

A data-analyst project answering one question: **which country-level
factors — wealth, social support, health, freedom — best explain national
happiness, and which regions are rising or falling?**

Built on a synthetic 159-country × 6-year panel (2019–2024) modelled on the
World Happiness Report's structure: correlation analysis, an OLS regression
that ranks the six happiness factors by effect size, regional trend lines,
and the biggest country climbers and fallers. Every number below comes from
a real run of `python/happiness_analysis.py` (run on 2026-10-01).

> All data is synthetic — generated by `data/generate_happiness_data.py`
> (seed = 42, fully reproducible) and calibrated to realistic WHR ranges.
> The *methods* transfer to the real World Happiness Report data; the
> specific numbers do not.

## Why, how, what

**Why** — every year the World Happiness Report ranks 150+ countries, but a
ranking alone doesn't tell a policymaker *what to fix*. If social support
moves happiness more than GDP, that changes where a country should invest.

**How** — (1) Generate a 954-row country-year panel with realistic regional
baselines, year trends, and noise (seeded, reproducible). (2) Measure the
headline KPIs: global average, top/bottom countries, regional rankings.
(3) Correlate each of the six factors with the ladder score. (4) Fit an OLS
regression on standardized factors to rank drivers by effect size and read
off R². (5) Track regional trajectories 2019–2024 and flag the biggest
country-level climbers and fallers. (6) Reproduce every headline KPI in SQL.

**What** — a reproducible happiness-analysis toolkit: labelled panel
dataset, one script that runs the full analysis, five charts, a SQL query
pack (`sql/queries.sql`) reproducing every headline KPI, and a written
answer to which factors matter most.

## Analytics type

| Type | How this project uses it |
|---|---|
| **Descriptive** (primary) | Rankings and trends: top/bottom countries, regional averages, the 2019–2024 trajectory of world happiness. |
| **Diagnostic** | Explains *why* happiness differs: correlations and the OLS regression rank the six factors by effect size. |
| **Predictive** | The regression model predicts a country's ladder score from its six factors (R² = 0.878) — the same equation scores any new country-year. |
| **Prescriptive** | Points *where to invest*: a 1-SD lift in social support (+0.315) moves happiness nearly as much as a 1-SD lift in GDP (+0.380) — cheaper levers exist. |

## SQL analysis layer

Every headline KPI is also computed directly in SQL — the same aggregations
an analyst would run against a production country-statistics table.
[`sql/queries.sql`](sql/queries.sql) (MySQL 8 compatible) reproduces, all exact:

- **global average ladder (2024)** — 5.318 across 159 countries
- **top 10 countries** — Finland 7.854, Belgium 7.850, Norway 7.686
- **bottom 5 countries** — Afghanistan 2.294, South Sudan 2.930, Mozambique 3.184
- **avg ladder by region** — Western Europe 7.037 (best) → Sub-Saharan Africa 4.175 (worst)
- **avg ladder by GDP quartile** — Q1 (poorest) 4.035 · Q2 5.059 · Q3 5.608 · Q4 (richest) 6.604
- **biggest climber / faller 2019→2024** — Serbia +0.909, Cyprus -0.961
- **YoY global trend** — 2019 5.285 → 2024 5.318 (nearly flat, +0.033)

SQL handles the extraction, aggregation, and KPI computation; Python handles
the statistical modelling (correlations, OLS regression), charts, and the
written findings.

## Dataset

`data/happiness.csv` — 954 rows (159 countries × 6 years, 2019–2024),
generated by `data/generate_happiness_data.py` (seed = 42).

| Column | Description |
|---|---|
| country | Country name |
| region | 8 WHR-style regions (Western Europe, North America, Latin America, Middle East, Sub-Saharan Africa, South Asia, East Asia, Central/Eastern Europe) |
| year | 2019–2024 |
| ladder_score | Cantril ladder happiness score (0–10) |
| log_gdp_per_capita | Log of GDP per capita |
| social_support | Perceived social support (0–1) |
| healthy_life_expectancy | Healthy life expectancy (years) |
| freedom | Freedom to make life choices (0–1) |
| generosity | Generosity (0–1) |
| corruption_perception | Perceived corruption (0–1) |

> Synthetic panel modelled on World Happiness Report structure. Ladder
> scores are constructed from the six factors (plus regional trends and
> noise), so factor correlations hold by construction — the project
> demonstrates the *analytical method*, not real-world findings.

- **OLS regression (standardized, n = 159):** **R² = 0.878**. Effect of a
  +1 SD move in each factor: log GDP **+0.380** · social support **+0.315** ·
  healthy life expectancy +0.178 · freedom +0.166 · corruption -0.127 ·
  generosity +0.023. Wealth is the strongest driver, but social support is
  close behind — and far cheaper to move than GDP.
- **Wealth vs happiness:** GDP–ladder Pearson r = 0.858 in 2024, but the
  scatter shows wide vertical spread at every income level — money explains
  a lot, not everything.
- **Regional trajectories 2019→2024:** Central/Eastern Europe rose most
  (**+0.291**); Latin America fell most (**-0.192**). Western Europe barely
  moved (+0.041).
- **Biggest climbers:** Serbia **+0.909** · Mongolia +0.841 · Lesotho
  +0.823 · France +0.821 · Azerbaijan +0.819.
- **Biggest fallers:** Cyprus **-0.961** · Taiwan -0.908 · Mali -0.871 ·
  Peru -0.826 · El Salvador -0.761.
- **GDP quartiles:** poorest-quartile countries average 4.035 vs 6.604 for
  the richest — a 2.57-point happiness gap by wealth.

### What a policymaker should take away (prescriptive)

1. **Social support is the high-ROI lever** — nearly the effect of GDP
   (+0.315 vs +0.380 per SD) without needing a richer economy first.
2. **Health buys happiness** (+0.178 per SD): healthy-life-expectancy gains
   show up directly in ladder scores.
3. **Corruption is a happiness tax** (-0.127 per SD): cleaner institutions
   lift scores even at fixed income.
4. **Generosity barely registers** (+0.023) in this data — don't build a
   national strategy on it.

## Methods

- **Panel EDA** — global average, rankings, regional means, YoY trend.
- **Pearson correlations** — each factor vs ladder across all 954 rows.
- **OLS regression** (`sklearn.linear_model.LinearRegression`) on
  standardized factors; standardized coefficients rank drivers by effect
  size; R² measures explanatory power.
- **Regional panel trends** — yearly regional means; 2019→2024 change flags
  risers and fallers.
- **Country movers** — per-country ladder change 2019→2024 via pivot.
- **GDP quartiles** — `NTILE(4)` over log GDP per capita (MySQL 8), the
  classic wealth-vs-outcome cut.

## Limitations

- Synthetic data with baked-in factor relationships — the *methods* transfer
  to the real World Happiness Report; the specific numbers do not.
- The OLS model is associational, not causal: richer, healthier, freer
  countries are happier, but the regression alone can't prove the direction.
- Regional trends are linear by construction in the generator; real regional
  trajectories are noisier and event-driven.
- Generosity's near-zero effect reflects how it was generated here, not a
  real-world claim about generosity.
